🧩 Jogo Sudoku em Java
📌 Sobre o Projeto

Este projeto consiste na criação de um jogo Sudoku desenvolvido em Java, com o objetivo de praticar conceitos de programação orientada a objetos, estruturas de dados e lógica de validação.

O jogo permite que o usuário preencha um tabuleiro 9x9 seguindo as regras clássicas do Sudoku.

🎯 Objetivos

Praticar lógica de programação

Aplicar Programação Orientada a Objetos (POO)

Trabalhar com matrizes (arrays bidimensionais)

Implementar validações de regras do jogo
